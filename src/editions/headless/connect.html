CCTV HEADLESS ENGINE

Hubungkan aplikasi ke engine AI

Server sudah merespons. Gunakan halaman ini untuk mengecek koneksi dan mencoba API. Engine tetap berjalan saat halaman ditutup.

1. Hubungkan dengan token

Token diberikan oleh administrator saat pemasangan. Pilih file token.txt atau tempel token di bawah. Token hanya disimpan di memori tab ini.

Belum terautentikasi.

2. Status engine

Alamat integrasi:
Autentikasi: Authorization: Bearer <token>



3. Tambahkan kamera
Masukkan URL RTSP dari kamera atau NVR. Registrasi belum memulai analisis. Simpan konfigurasi kamera di server jika perlu tersedia otomatis setelah restart.




Untuk uji deteksi: pilih endpoint POST /cameras/{camera_id}/start di bawah dan gunakan ?preview_only=true. Untuk pencatatan zona, simpan kalibrasi melalui endpoint PUT .../analytics terlebih dahulu.


4. Coba API
Pilih endpoint, isi parameter pada alamat dan body JSON bila diperlukan, lalu kirim. Operasi POST, PUT, dan DELETE mengubah state engine.






Hasil request akan tampil di sini.


WebSocket: /api/v1/stream dengan header Bearer dari client integrasi. Webhook diatur oleh administrator melalui konfigurasi server.


Belum punya token atau lisensi? Minta paket konfigurasi kepada administrator. Jangan mengirim token melalui URL atau membagikan file token ke publik.
